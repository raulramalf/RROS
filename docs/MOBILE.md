# Móviles

## Android
Viable vía: (a) portar RROS a dispositivos concretos usando la base de **postmarketOS/Ubuntu Touch**, o (b) entorno de escritorio táctil sobre Android. Empezar con 2–3 modelos con bootloader desbloqueable.

## iPhone
**No viable**: Apple bloquea el arranque de sistemas operativos no firmados y no hay drivers abiertos. Se descarta salvo una app/cliente remoto.

## Estrategia
Perfil **Mobile** separado (táctil, bajo consumo, ARM64). No entra en la primera versión.
